## 运行

先安装项目依赖，并为这个可选的浏览器测试安装 Playwright 与 Chromium：

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
npm run build
npm run test:pdf -- --download
```

`--download` 只在本地缺少样本时从上表的公开来源下载。无此参数时只读取本地缓存。测试使用独立的临时浏览器资料目录和本地模拟翻译服务，不使用个人浏览器的配置或真实 API 密钥。

```sh
# 长译文压力测试
npm run test:pdf -- --expanded

# 检查 Windows 常见的 125% 屏幕缩放
npm run test:pdf -- --ids=admm --device-scale=1.25

# 通过 URL 打开后立即翻译，重新打开缓存文档，并滚动后连续重译三次
# PDF_TEST_BROWSER 也可以指向本机 Edge 的 msedge.exe
npm run test:pdf -- --ids=admm --auto-open --repeat=3 --device-scale=1.25

# 在独立测试资料目录中注入浏览器最小字号限制
npm run test:pdf -- --ids=admm --auto-open --repeat=3 --minimum-font=48

# 模拟服务持续丢失公式标记，验证段落重试及仅翻译正文的恢复流程
npm run test:pdf -- --ids=pmlr,attention --damage-markers

# 加入本地问题文档，包含第 3、5、8 页抽查图（若存在）
npm run test:pdf -- --file="/absolute/path/paper.pdf"
```

若使用现有 Chromium，可将其可执行文件路径写入 `PDF_TEST_BROWSER`。若 Playwright 安装在项目外，可将其 `index.mjs` 绝对路径写入 `PLAYWRIGHT_MODULE`。

## 检查内容与边界

每个样本的全部页面都经过实际扩展的文件选择、文字提取、服务请求、预览渲染与 PDF 下载流程。脚本检查失败页、未捕获错误、可编辑文字的横纵溢出、导出页数与纸张尺寸，并输出重点页面的原译文对照截图。PLOS 第 19 页方程组另有原文与译文底图的严格像素一致性检查，用来拦截大括号丢失、截断等问题。Transformer 第 14 页另检查图表与旋转标签，允许重复绘制半透明路径时最多 8/255 的色值舍入差异，以及最多 0.001% 的边缘像素差异。

常规模拟译文还要求所有文字块不低于初始推荐字号的一半。ADMM 第 2、5 页使用固定中文片段，单独检查字号至少达到推荐值的 75%、三个列表项保持独立，以及真实“− / +”按钮对正文和公式的同步缩放。`fonts` 记录内部画布字号与推荐字号的比例；这个比例不受屏幕像素倍率影响。固定中文和其他模拟译文均不代表真实服务输出。

下载前先检查译文首个可见字形与文本框相交、字号比例正常，并拒绝出现无法适配的文字块。`--repeat` 开启缓存，每次确认全部段落命中且没有新增服务调用，再检查即时与延迟后的预览。`--auto-open` 同时覆盖 URL 自动翻译与页面重新加载。字体限制故障注入仅写入独立的临时测试资料目录。

普通、长译文、标记损坏模式的输出分别在 `latest/`、`expanded/`、`recovery/`；`report.json` 包含尺寸、公式数量、溢出和过小字号信息。应继续人工查看截图，并用 Poppler 或独立 PDF 阅读器抽查导出文件。

当前修复覆盖：

- 从接近原文的字号开始，按浏览器实际字体和换行查找能容纳的最大字号，避免多换一行就一次缩到一半；行距参考原文。
- 先同步图层尺寸和缩放，再测量文字；忽略空 Range 或异常偏移，验证二分查找的最小候选是否真的可放下。无有效候选时保留初始字号，避免提交 1px 与异常顶部留白造成“译文消失”。
- 沿用 PDF.js 测得的浏览器最小字号，通过放大文字坐标再反向缩放保持实际 PDF 字号；导出换算回画布坐标。裁剪容器约束测量图层的溢出范围，并留出工具栏空间。
- 翻译按钮在保存设置之前立即锁定，避免快速点击连续启动任务、反复清空预览；保存失败后恢复可操作状态。
- 行内公式使用实际字形边界，避免 CMSY 等字体的全局下沿把邻行正文截进公式图片，并撑高整段行距。
- 数学字体中的项目符号保留为结构标记，维持列表分项与悬挂缩进；居中标题保持居中，普通正文保持左对齐。
- 选框工具栏提供“− / +”，每次调整一个 PDF 字号单位；正文、行距和公式同步缩放，导出读取当前样式。手动放大时仅利用下一处正文或保留公式之前的空白。
- 编辑框边界不再占用文字空间，也不会强行撑宽窄表格单元格。
- 预览与导出使用相同的实际文字位置，避免导出时重新换行造成差异。
- 旋转角度、裁边起点、PDF 单位统一到显示坐标；倾斜图内标签保留原文像素。
- 补充 TeX、PI 和数学罗马字体识别，避免将变量乘积当成自然语言。
- 数学扩展字体中的冒号等编码可代表括号部件，不能按普通标点剥离；大括号下沿需要额外留出空间。
- 从 PDF 文字绘制操作移除原文，包含绕过 Canvas `fillText` 的路径字体，避免原文残影。
- 提取时遵循图形裁剪框、默认图层可见性、不可见文字模式和透明度，避免把被裁掉的标题、关闭的图层或隐藏 OCR 文字显示在译文中。

绘制过滤读取 PDF.js 当前 render task 的内部指令列表。`getOperatorList()` 返回的未优化列表与实际绘制列表的序号不同，不能混用；升级 PDF.js 时必须执行这组浏览器回归，尤其是 Transformer 第 14、15 页的密集图表。

模拟译文用于可重复的排版与故障恢复测试，不能替代真实 DeepSeek 的语义质量和网络稳定性验证。极长译文在密集表格或很小的图内标签中仍可能缩成较小字号，可手动调整译文块；倾斜标签目前保持原文。扫描 PDF 的 OCR 不属于这组文字型 PDF 回归的覆盖范围。
